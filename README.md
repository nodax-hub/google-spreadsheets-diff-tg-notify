## Google Sheets Watcher (Telegram Bot)

Сервис отслеживает изменения в указанных диапазонах **публичных Google Sheets** и уведомляет подписанных пользователей через **Telegram-бота**.

### Основные возможности

* периодически читает заданные диапазоны ячеек Google Sheets (через CSV-экспорт)
* сравнивает текущее значение с предыдущим
* сохраняет состояние в энергонезависимое хранилище (SQLite)
* отправляет уведомление в Telegram при обнаружении изменений
* поддерживает подписку на **несколько диапазонов**
* позволяет:

  * подписываться и отписываться одной ссылкой
  * просматривать список своих подписок

### Технические детали

* язык: **Python 3.12**
* бот: **python-telegram-bot 20.x (polling + JobQueue)**
* хранилище: **SQLite** (в Docker volume)
* планирование: **JobQueue / APScheduler**
* логгирование: стандартный `logging`, Docker-friendly
* развёртывание: **Docker / docker-compose**
* архитектура: модульная, с `src/` и единой точкой входа

### Формат подписки

Пользователь отправляет боту ссылку вида:

```
https://docs.google.com/spreadsheets/d/<spreadsheet_id>/edit?gid=<gid>#gid=<gid>&range=<A1_range>
```

### Назначение

Проект предназначен для автоматического мониторинга изменений в Google Sheets
(расписания, статусы, показатели, таблицы учёта) без использования Google API и OAuth,
с простым и прозрачным управлением через Telegram.



## Развёртывание и запуск

### Требования

* Docker **20.10+**
* Docker Compose **v2**
* Telegram Bot Token (через `@BotFather`)

---

### Клонирование репозитория

```bash
git clone https://github.com/nodax-hub/google-sheets-watcher.git
cd google-sheets-watcher
```

---

### Настройка окружения

В репозитории есть пример файла окружения `.env.example`.

Скопируй его в `.env` одной командой:

```bash
cp .env.example .env
```

Открой .env и укажи:

TELEGRAM_TOKEN — обязательно

CHECK_INTERVAL_SECONDS — период проверки (в секундах)

---

### Сборка и запуск

```bash
docker compose up -d --build
```

Контейнер запустится в фоне, бот начнёт polling.

---

### Просмотр логов

```bash
docker compose logs -f
```

Логи пишутся в `stdout`, формат подходит для Docker / Kubernetes.

---

### Остановка сервиса

```bash
docker compose down
```

Данные (подписки и состояние) **не удаляются**, так как хранятся в Docker volume.

---

### Проверка работы

1. Найди бота в Telegram
2. Отправь команду:

   ```
   /start
   ```
3. Подпишись, отправив ссылку вида:

   ```
   https://docs.google.com/spreadsheets/d/<spreadsheet_id>/edit?gid=0#gid=0&range=B71:F71
   ```
4. Измени данные в Google Sheets
5. Дождись уведомления

---

### Хранение данных

* используется SQLite
* база данных хранится в Docker volume:

  ```
  /data/data.db
  ```
* перезапуск контейнера **не сбрасывает подписки**

---

### Обновление версии

```bash
git pull
docker compose up -d --build
```

---

### Удаление всех данных (осторожно)

```bash
docker compose down -v
```

Удаляет контейнер **и** volume с базой данных.
